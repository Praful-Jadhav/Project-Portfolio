# Public Portfolio — Zero-Trust Publication Contract

This repository is a public publication surface. Every claim, link and displayed capability must be reviewed as an external-facing statement.

## Trust rule
A generated page, file, successful build or AI summary is not proof that the public artifact is correct. Inspect the actual diff and rendered behavior. A few lines or a checked box do not prove completion.

## Publication rules
- Publish only approved, evidence-backed claims. Clearly distinguish current capabilities from prototypes, plans and research.
- Do not invent clients, revenue, testimonials, credentials, certification, performance or production status.
- Keep internal strategy, private data, client records, credentials, tokens and operational instructions out of public files.
- Check links, page metadata, accessibility basics, local assets and navigation targets before acceptance.
- External-facing changes require a packet under docs/evidence/ recording claim ID, owner, risk, scope, review method, validation, limitations and exact revision.

The CI gate checks structural evidence only. It does not prove a public claim is true or substitute for a real browser/readability review.
